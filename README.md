# Fast-Trajet
Une application de geolocalisation qui permet aux clients de trouver facilement un chauffeur dans la ville de Kinshasa 

Problème résolu

Fast Trajet est une application Web conçue pour faciliter la mise en relation entre les clients et les chauffeurs de taxi dans la ville de Kinshasa grâce à la géolocalisation.

L'application vise notamment à réduire le temps passé par les clients à chercher un taxi et les déplacements inutiles des chauffeurs à la recherche de clients, tout en renforçant la sécurité et le suivi des courses.


🛠️ Technologies utilisées

Fast Trajet a été développé comme une application Web avec :

- HTML5 / CSS3 — structure et présentation des interfaces.
- JavaScript — interactions, géolocalisation et mises à jour côté navigateur.
- PHP 8.2 — traitement côté serveur et API.
- MySQL / MariaDB — stockage et gestion des données.
- XAMPP / Apache — environnement de développement et serveur Web local.
- Leaflet — affichage et manipulation des cartes.
- OpenStreetMap — données cartographiques.
- Nominatim — conversion entre coordonnées GPS et adresses.
- OSRM — calcul des itinéraires, distances et durées.
- VS Code — environnement utilisé pour le développement.


 Fonctionnalités principales

Fast Trajet permet notamment la création et la connexion des comptes clients et chauffeurs, la géolocalisation, la recherche et la commande d'un taxi, l'affichage des courses disponibles aux chauffeurs, l'acceptation d'une course, la négociation du prix avant le départ, la messagerie client–chauffeur après accord, le calcul de l'itinéraire, de la distance et de la durée, le suivi géographique pendant la course, les notifications, le signalement d'incidents ainsi que la gestion administrative des utilisateurs, courses et alertes.


💻 Installation et lancement

Pour exécuter Fast Trajet localement :

Installer XAMPP.
Placer le dossier fast-trajet-v2 dans :
C:\xampp\htdocs\
Démarrer Apache et MySQL depuis XAMPP.
Créer/importer la base de données fast_trajet_v2 avec phpMyAdmin.
Vérifier la configuration de connexion dans config/database.php.
Ouvrir le navigateur et accéder à :
http://localhost/fast-trajet-v2/

Certaines fonctionnalités cartographiques nécessitent également une connexion Internet, puisque le projet utilise des services externes de cartographie et de géolocalisation.
